**Open corpora and NLP models for Early Modern French (16th–18th centuries).** FreEM provides training data and models for lemmatisation, part-of-speech tagging, morphology, spelling normalisation and named entity recognition.

🌐 **Website:** [freem-corpora.github.io](https://freem-corpora.github.io/)

## Corpora and models

| Resource | What it contains | Data |
|---|---|---|
| [**FreEMlpm**](https://github.com/FreEM-corpora/FreEMlpm) | Lemmas, POS tags and morphology for 16th–18th c. French | [Zenodo](https://doi.org/10.5281/zenodo.6481299) |
| [**FreEMnorm**](https://github.com/FreEM-corpora/FreEMnorm) | Parallel corpus (original / normalised spelling) | [Zenodo](https://doi.org/10.5281/zenodo.5865427) |
| [**FreEMmax_OA**](https://github.com/FreEM-corpora/FreEMmax_OA) | Open-access corpus for training language models | [Zenodo](https://doi.org/10.5281/zenodo.6481134) |
| **D’AlemBERT** | RoBERTa model pre-trained on FreEMmax | [Hugging Face](https://huggingface.co/pjox/dalembert) |
